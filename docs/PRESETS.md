# Factory presets

Bizar ships 128 original presets, sixteen in each of eight categories. The two-letter tag at the start of each name is its category, so the list stays easy to browse on Move's display. Arpeggios and sequences follow Move's tempo and start when you hold a key.

Every preset has two macros: **1 Timbre** sweeps the filter and moves the engines' signature controls and the drive with it, and **2 Space** raises the delay, reverb and release. Presets built on an LFO add **Macro 3, Motion**: the knob is the LFO's depth.

This file is generated by `scripts/generate_factory_bank.py --markdown docs/PRESETS.md`; edit the script, not this list.
