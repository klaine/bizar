# Contributing to Bizar

Bug reports, preset ideas and pull requests are welcome. For anything bigger than a small fix, open an
issue first so we can agree on the approach.

- **Branch:** fork, branch from `main`, and open the pull request against `main`. Don't touch the
  `pages` branch: it's generated by `scripts/pages.sh` and replaced on every publish.
- **Build and test:** `CC=cc sh scripts/build.sh --test` runs the desktop DSP and integration tests,
  and `sh scripts/build.sh` builds `dsp.so`, the package and the web synth (the device build needs
  zig or an aarch64 gcc). CI runs the same on every pull request, so it must pass.
- **Generated docs:** CI fails if `PARAMETER_REFERENCE.md` or `docs/PRESETS.md` are stale. After
  changing a parameter, a range or a factory preset, run `sh scripts/build.sh --reference` and commit
  both files.
- **Saved patches:** engine and effect indices are part of saved state, so append new ones. If an
  index has to move, bump the state version, add the migration to `apply_state_json` and explain it
  in `CHANGELOG.md`.
- **Changelog:** every user-visible change gets an entry under "Unreleased" in `CHANGELOG.md`.
- **UI:** `web_ui.html` carries `web_ui_extras.js` inlined between the `sfx` markers. Edit the `.js`
  file, not the inlined block.
- **Realtime:** no file I/O and no heap allocation in plugin callbacks.
- **Warnings:** builds use `-Wall -Wextra -Werror` with both gcc (CI) and clang (zig). Keep both clean.
- **No Arturia material.** Bizar contains no Arturia code, firmware, presets or sample data, and pull
  requests must not add any: no MiniFreak exports (`*.mnfx`), renders or preset dumps, and nothing
  derived from them. Factory presets must be original.

By contributing you agree your work is released under the repository's [LICENSE](LICENSE).
